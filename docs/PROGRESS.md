## 🔧 데이터 파이프라인 (스팟 추가/갱신 시)

```bash
npm run db:setup          # 스키마+시드 (최초 1회 또는 스키마 변경 시)
npm run db:sync           # KTO areaBasedList2 → night_spots 적재/갱신
npm run db:classify       # 운영시간 수집(detailIntro2) + Gemini 야간 후보 분류
# → 후보를 사람이 검수한 뒤 night_verified=true 처리 (SQL)
npm run etiquette:pregen  # 가이드·표현 사전생성 (한도 걸리면 GEMINI_MODEL=gemini-flash-lite-latest로)
```

**노출 규칙**: `night_verified = true` **AND** `image_url IS NOT NULL` (사진 필수 방침)

## 📌 앞으로 할 일 (우선순위순)

**담당: 임찬혁 (이 두 개만, 다른 파일 수정 최소화)**
1. **추천 코스** — KTO 연관 관광지 API(차량 이동 통계 기반) + 지도 폴리라인. "차량 이동 기반 근교 야경 코스"로 프레이밍 (데이터 성격 명시). 심사 "데이터 활용 적절성" 핵심 기능
2. **커뮤니티** — 가볍게: 스팟별 한줄 후기/질문 정도로 시작 (Supabase 저장). ⚠️ 빈 커뮤니티는 심사 감점 요인이라, 오픈 전에 팀이 시드 글을 채우는 것까지가 완성. 로그인은 이름만 입력하는 수준으로 단순하게

**담당: 박성민**
3. **KTO 운영계정 신청** — data.go.kr 마이페이지, 서비스 URL(tournight.vercel.app) 등록. 심사 제출 필수, 승인 소요 있으니 빨리
4. **숙소 기능** — KTO `searchStay2`(대전 areaCode=3), 스팟 인근 거리순
5. **사진 확보** — 대전0시축제(8월 개최 때 직접 촬영 추천), 대전시민천문대(공공누리 확인). 확보 시 해당 스팟 노출 재개
6. **0시축제 데이터 복귀** — KTO가 2026 일정 등록하면 `db:sync` + `db:classify` 재실행
7. **기능설명서 PPT** — 양식 확보됨(대회 폴더). 핵심기능 5개 구성안: 야간명소 탐색+자연 연계 / 추천 코스 / 숙소 / AI 가이드·서바이벌 한국어 / 다국어
8. Vercel Git 자동배포 연동 (선택), PWA (보류)
